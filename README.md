## Overview

**Megalohydrothalassophobia: Into the Abyss** places the user at the ocean surface before triggering an uncontrollable, linear sink rate through four distinct oceanic light zones down to an abyssal depth of 480 meters. 

Built with **A-Frame** and the **Web Audio API**, the experience combines dynamic depth telemetry, automated lighting transitions, depth-tiered procedural creature spawning, and a contextual soundscape that scales in intensity with hydrostatic pressure.
